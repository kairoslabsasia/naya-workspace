# 🚀 PANDUAN DEPLOY CPANEL (VERSI PHP MURNI - 100% PASTI JALAN)

Paket ini dibuat khusus agar **100% kompatibel dengan cPanel Shared Hosting Paket Basic** tanpa memerlukan Node.js, tanpa kartu kredit, dan tanpa upgrade hosting!

---

## ⚡ CARA PASANG (HANYA 1 MENIT)

### 1. Buka File Manager di cPanel
1. Buka tab **cPanel File Manager** di browser Anda.
2. Masuk ke folder subdomain Anda (folder: `test.kairoslabs.id` atau folder web yang Anda gunakan).
3. Hapus file/folder lama yang ada di dalamnya agar bersih (termasuk folder `node_modules` lama yang tidak diperlukan lagi).

### 2. Upload & Ekstrak ZIP
1. **Upload** file **`naya-cpanel-php.zip`** ke dalam folder tersebut.
2. Klik kanan file zip tersebut > pilih **Extract** (Ekstrak di tempat).

### 3. Selesai!
Buka URL di browser:
👉 **`https://test.kairoslabs.id`**

🎉 **Website langsung aktif normal!**
Tampilan *"Index of /"* langsung hilang dan berganti menjadi halaman login Naya Workspace yang elegan!
